## 明确的解释与改编

- 地平线矩形题的原帖将“重叠面积”和 IoU 混称：`extra/rectangle_overlap.py` 实现面积，`ai/iou_nms.py` 另外实现 IoU。
- 字节有序 List 交集未交代重复次数，当前采用集合语义，结果去重；若要求多重集交集，去掉相等分支的去重跳过即可。
- 字节工具日志、小红书热度去重、京东城市金额和快手流式 JSON 只给主题；完整接口、并列规则、金额单位、帧类型均为练习约定，不宣称还原原平台全部隐藏条件。
- 阿里等面经里的 KNN、SVM、LoRA、强化学习口述题，不自动标注为该公司的代码题。AI 目录大部分是通用备考补充。
