# 解法选择与“最优”的边界

Hot100 优先采用原题约束下时间或空间有优势的标准解法。文件头同时列出时间与额外空间；“最优”不能理解成所有机器、所有输入规模下都唯一最快。

| 情况 | 本仓库选择 / 需要知道的边界 |
|---|---|
| 第 K 大 | 随机三路快速选择：期望 O(n)，最坏 O(n²)；若必须保证最坏上界，可用 O(n log k) 堆或 BFPRT |
| 最长回文子串 | Manacher O(n) 时间和空间；中心扩展更容易白板解释，但最坏 O(n²) |
| 链表排序 | 自底向上归并，O(n log n) 时间、O(1) 辅助空间 |
| 爬楼梯 | 快速倍增 Fibonacci，O(log n) 次算术运算；Python 大整数的位成本不能视作永远 O(1) |
| 完全平方数 | 数论 + 枚举，O(sqrt(n)) 时间、O(1) 辅助空间；需要理解四平方和定理 |
| 分割等和子集 | Python 大整数位集实现可达和；按机器字分析为 O(nS/w)，不是与 S 无关的 O(n) |
| 不同路径 | 组合数计算；如果考官希望考 DP，可解释一维滚动数组 |
| 搜索二维矩阵 II | 从右上角排除一行或一列，O(m+n)；极窄矩阵可按行二分更划算 |
| 回溯枚举 | 全排列、子集、N 皇后必须承担输出成本；不会把指数级输出算法写成线性 |
| 最小生成树补充题 | Manhattan 完全图用 O(n²) Prim，适合原题规模；并非利用几何结构后的理论最快算法 |
| 冒泡排序补充题 | 考察排序过程，最坏 O(n²)；通用排序选归并、堆排或 Python 内置排序 |
| K-means / 梯度下降 | 教学迭代实现；K-means 不保证全局最优，回归迭代次数由容差/学习率决定 |
| Beam Search | 有限束宽近似解码，不保证全局最优序列；这里未加长度惩罚 |
| KNN / Top-p / 余弦 Top-k | 使用稳定排序明确并列行为；可用选择或堆降低仅取少量结果时的排序成本 |
| PCA | 用 NumPy SVD 求数值分解；不等于手写 SVD，也不借助 sklearn |

算法文件默认输入满足各题约束；它们是手撕练习，不是覆盖所有非法输入的生产 API。NumPy 模块输入应是有限数值，并满足文件头的形状说明。矩阵乘法的复杂度采用通常的稠密乘法模型；Attention 的复杂度需乘以前导 batch/head 数。

测试能发现实现与约定的偏差，但不等于已在 LeetCode 官方判题器提交 AC，也不构成对所有输入的正确性证明。
