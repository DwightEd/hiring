## 排序键、元组与堆

```python
# 第一关键字：分数从高到低；第二关键字：下标从小到大。
order = sorted(range(len(scores)), key=lambda j: (-scores[j], j))
```

`lambda j: ...` 是一个临时函数，收到下标 `j`，返回排序依据。Python 按元组第一项比较，相等再比较第二项。`sorted()` 默认升序，所以分数前面加负号。

`heapq` 是最小堆。保留最好的 T 项时，堆顶应该是“最差的已选项”，因此键用 `(score, -index)`。新键更大才替换堆顶。这与上面的全量排序键正好对应。

`list.sort()` 原地修改并返回 `None`；`sorted(list)` 返回新列表。前者省掉一份输出列表，但 Python 的排序仍可能使用 O(n) 工作空间。

## 容器与常用语法

| 写法 | 含义 / 易错点 |
|---|---|
| `enumerate(nums)` | 同时取下标和值 |
| `zip(a, b)` | 成对遍历，长度不同时在较短者处结束 |
| `set(a) \| set(b)` | 集合并集，交叠元素只保留一次；不保证顺序 |
| `d.get(key, 0)` | 键不存在时返回默认值，不插入 |
| `d.setdefault(key, i)` | 只在不存在时插入，适合保存最早下标 |
| `deque.popleft()` | O(1) 出队；`list.pop(0)` 是 O(n) |
| `a[::-1]` | 创建反向副本，O(n) 时间和空间 |
| `//` | 向下取整；负数结果与截断到零不同 |
| `is` / `==` | 节点是否同一对象 / 值是否相等 |
| `[[0]*m for _ in range(n)]` | 创建独立的 n 行；不要用 `[[0]*m]*n` |

## 复杂度里容易漏掉的成本

循环中 `s += piece`、反复切片、`x in list` 都可能带来额外线性成本；拼字符串优先列表收集后 `''.join(parts)`。集合和字典查询通常是期望 O(1)，不是任意输入下的确定最坏 O(1)。

Python 默认递归深度有限。本仓库深树的路径和、直径、最近公共祖先等用显式栈；回溯题的深度通常由原题较小的参数决定。不要一遇到深树就只把递归上限调到极大。

## 面试时如何讲

先确认数据范围和边界，再说状态或不变量，最后给复杂度。例如“前缀和最早位置始终不覆盖，因此固定右端点时能得到最长左端距离”。对于矩形先问坐标是连续坐标还是像素闭区间；对于排名先问并列规则；对于数组交集先问重复次数是否保留。
