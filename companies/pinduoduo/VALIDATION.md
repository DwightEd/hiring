## 规模计时

环境：Linux x86-64，CPython 3.13.5；C++ 使用 g++ 14.2.0、`-O2 -std=c++17`。固定随机种子 922，仅一次代表性计时，不是最坏情况保证。

| 实现 | 数据 | 本机时间 | 计时口径 |
|---|---|---:|---|
| 果园 Python | n=1000，c=500，坐标在 1 到 10^9 范围内随机生成 | 0.166 秒 | 完整 minimum_side 调用，不含输入解析 |
| 括号 Python | n=200000，初始串为重复的 () | 0.164 秒 | 建树 |
| 括号 Python | q=200000，翻转/查询交替，端点随机合法 | 5.622 秒 | 操作执行，不含输入生成、I/O 与建树 |
| 括号 C++17 | 同一初始串和相同的 200000 个操作 | 0.194 秒 | 子进程运行，含建树与 I/O，不含编译 |

括号操作包含 100000 次翻转和 100000 次查询，随机区间包括奇数长度，程序对奇数长度查询直接输出 NO。C++ 大规模运行产生 100000 行查询输出；该次规模计时未对全部输出重新做暴力比对，正确性对照使用上面的独立小数据测试。

截图给出 1000 ms 限制，Python 在上述本机样本中明显超过 1 秒。若原平台严格执行同等时限，应优先考虑附带 C++17；具体语言倍率、机器、编译选项和测试分布仍影响能否通过。不能把渐近复杂度正确或本机计时当成官方 AC。
