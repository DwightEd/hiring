# 第一题：货架最少搬运次数

来源：用户提供的题面截图，页面标题标注“拼多多 2026-9-22”。题面规则、输入输出和约束整理如下；公司及日期沿用截图标注，未独立核实为公司官方发布。截图可见样例输入，但未显示输出。

## 题目描述

仓库有 `N` 个货架，第 `i` 个货架上有 `A_i` 件商品。每天机器人都会从左到右经过所有货架。

机器人支持一种操作：选择一个连续区间 `[l, r]`，一次性搬走这一段货架上的所有商品。但是由于机械臂限制，一次操作只能搬走一段中商品数量完全相同的货架。

例如：`2, 2, 2` 可以一次搬走；`2, 3, 2` 不能作为一段一次搬走。问最少需要多少次搬运才能搬完全部商品。

这里搬走的是商品，不是把货架删除后重新拼接；区间按原有货架位置理解。

## 输入描述

第一行一个整数 `T`，表示共有 `T` 组测试数据。

每组数据第一行是整数 `N`，表示货架数量；第二行是 `N` 个整数 `A_1, A_2, ..., A_N`，表示各货架上的商品数量。

约束：

- `1 <= T <= 10`；
- `1 <= N <= 100000`；
- `1 <= A_i <= 100000`。

截图时间限制 1000 ms，空间限制 256 MB。

## 输出描述

每组测试数据输出一行，一个整数，表示最少搬运次数。

## 样例

下列输入在截图中完整可见：

```text
1
8
2 2 3 3 3 1 1 2
```

根据题意计算出的输出（不是截图中可见的官方输出）：

```text
4
```

对应 `[2,2] | [3,3,3] | [1,1] | [2]` 四个连续等值段。

## 解法

答案是连续等值段数：非空数组先计一段，每当 `A[i] != A[i-1]` 再加一。

正确性：一次操作不能跨越相邻数量不同的边界；每个最大等值段又可以一次搬完，所以下界和可达方案相同。

时间 `O(N)`，算法辅助空间 `O(1)`；保存输入数组本身需要 `O(N)` 空间。

易错：不能统计不同数值的个数；`[2,3,2]` 的答案是 3，不是 2。
