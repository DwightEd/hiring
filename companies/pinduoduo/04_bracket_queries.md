# 第四题：括号串翻转与合法查询

来源：用户提供的题面截图，页面标题标注“拼多多 2026-9-22”；未独立核实为公司官方发布。以下整理全部可见规则、输入输出和约束。截图底部补充说明截断，且没有完整输入输出样例；本页另给自编完整样例，不冒充原样例。

## 题目描述

给定一个长度为 `n` 的括号字符串 `s`，其中只包含 `(` 和 `)`。接下来执行 `q` 个操作，分为两类：

1. 区间反转 `F l r`：将区间 `s[l...r]` 中的所有括号种类翻转，即 `(` 变成 `)`，`)` 变成 `(`。
2. 子串合法性查询 `Q l r`：判断当前字符串的子串 `s[l...r]` 是否为合法括号序列。如果合法输出 `YES`，否则输出 `NO`。

这里“反转”是逐个交换括号种类，**不是把字符顺序倒过来**。各操作按输入顺序生效。

一个括号序列合法，当且仅当其中的所有左右括号能够正确匹配。例如 `()`、`(())`、`()()` 合法，`)(`、`(()` 不合法。

## 输入描述

第一行两个整数 `n, q`，满足 `1 <= n <= 200000`、`1 <= q <= 200000`。

第二行一个长度为 `n` 的字符串 `s`，仅由 `(` 和 `)` 组成。

接下来 `q` 行，每行描述一个操作 `F l r` 或 `Q l r`。下标从 **1** 开始，保证 `1 <= l <= r <= n`，区间两端都包含。

截图时间限制 1000 ms，空间限制 256 MB。

## 输出描述

每个 `Q l r` 操作输出一行 `YES` 或 `NO`。`F` 操作不输出内容。

## 自编完整样例（非截图原样例）

输入：

```text
4 7
(())
Q 1 4
F 2 3
Q 1 4
F 1 4
Q 1 4
Q 2 3
Q 1 1
```

输出：

```text
YES
YES
NO
YES
NO
```

第一次翻转后变成 `()()`；第二次翻转后变成 `)()(`。最后一个查询只有一个字符，不可能合法。

## 解法：前缀平衡 + 懒标记线段树

把 `(` 记为 `+1`，`)` 记为 `-1`。子串合法的充要条件是：

- 总和为 0：左右括号总数相同；
- 所有前缀和非负：任何位置都不会出现尚无左括号可配对的右括号。

例如 `)(` 总和为 0，但第一个前缀和是 -1，所以不合法。

### 节点保存什么

每个线段树节点表示一段字符，保存三个量：`sum` 为总和，`low` 为最小前缀和，`high` 为最大前缀和。前缀集合包含和为 0 的空前缀。

这里的前缀都相对于**当前节点区间自己的起点**，不是相对于整串开头。

### 如何合并左右两段 A、B

```text
sum  = A.sum + B.sum
low  = min(A.low,  A.sum + B.low)
high = max(A.high, A.sum + B.high)
```

一个前缀要么停在 A 内，要么包含完整 A 再进入 B，所以进入 B 时要加上 A 的总和。合并顺序不能交换，`()` 与 `)(` 的总和一样但合法性不同。

### 区间翻转如何更新

翻转括号种类相当于把整段中的 +1/-1 全部取负，因此：

```text
sum'  = -sum
low'  = -high
high' = -low
```

这也是为什么虽然查询只用到 sum 和 low，仍必须维护 high。

懒标记表示该整段已经被翻转，但尚未逐个更新孩子。父节点汇总立即更新；以后需要下到子区间时再下推。标记用异或合并：`lazy ^= 1`，因为翻转两次恢复原样。

Python 使用迭代线段树，修改前下推边界路径、修改后重算部分覆盖的祖先；查询从左右两侧收集片段时分别累计，最后按原顺序合并。C++17 使用递归线段树，实现相同的合并与翻转公式。

### 复杂度与易错点

建树 `O(n)`，每次修改/查询 `O(log n)`，空间 `O(n)`。

必须同时判断总和与最小前缀，不能只数左右括号；不能逐次重新扫描整个区间，那样最坏为 `O(nq)`。

输入的 1-based 闭区间 `[l,r]` 转换为程序中的 0-based 半开区间 `[l-1,r)`。奇数长度查询直接返回 NO，不改变任何状态。
