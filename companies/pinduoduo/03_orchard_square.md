# 第三题：果园最小收集边长

来源：用户提供的题面截图，页面标题标注“拼多多 2026-9-22”；未独立核实为公司官方发布。题目规则、输入输出和全部可见约束整理如下。原样例只拍到 `10 3`、`47 66`、`33 81`，后续 8 个点及输出缺失，不据此猜测原样例答案。

## 题目描述

AK 机在一片果园里摘苹果。果园可以看作由边长为 1 的正方形单元格组成的二维网格。

果园里有 `n` 个苹果，每个苹果位于不同的单元格中，位置用整数坐标 `(x_i, y_i)` 表示。

AK 机有一个一次性收集器，可以指定任意一块边长为正整数 `m`、由 `m^2` 个完整单元格组成的正方形区域，并将区域内的苹果全部收集。指定区域越大，耗费的能源越多。

在至少收集 `c` 个苹果的条件下，希望区域尽可能小。请输出所选正方形区域的最小边长。

## 输入描述

第一行两个正整数 `n, c`，满足 `1 <= c <= n <= 1000`。

接下来 `n` 行，每行两个整数 `x_i, y_i`，满足 `1 <= x_i, y_i <= 10^9`。所有苹果所在位置两两不同。

部分测试数据满足 `1 <= x_i, y_i <= 1000`，但实现必须处理完整的 `10^9` 坐标范围。

截图时间限制 1000 ms，空间限制 256 MB。

## 输出描述

输出一个正整数：至少收集 `c` 个苹果所需的正方形区域最小边长。

## 自编完整样例（非截图原样例）

输入：

```text
4 3
1 1
2 1
1 2
10 10
```

输出：

```text
2
```

左下的三个苹果都处于一个 `2×2` 的单元格区域内。

## 最重要的边界：格子数量要加 1

覆盖一组选定单元格需要的最小边长是：

`max(max_x-min_x, max_y-min_y) + 1`。

例如单元格 `(1,1)`、`(2,1)` 需要边长 2，而不是 1。边长 `m` 能覆盖某些点的条件是两个坐标极差都**小于 m**。

## 解法：二分边长 + 扫描线 + 区间加最大值

### 1. 二分答案

给定边长 `m`，判断能否覆盖至少 `c` 个苹果。若可行，更大边长也可行。二分范围为 `[1, U]`，其中 `U=max(所有点的 x 极差, 所有点的 y 极差)+1`。

### 2. 用 x 滑动窗口限制横向宽度

将苹果按 x 排序，逐个加入右端点；当 `x_right-x_left >= m` 时移除左端点。窗口里的横向跨度都能被边长 m 容纳。

此时问题变成：窗口内，是否有一个长为 m 个格子的纵向区间，包含至少 c 个苹果？

### 3. 把每个苹果转换为“它允许的底边区间”

若正方形下边的单元格坐标为 b，位于 y 的苹果被覆盖需要：

`b <= y <= b+m-1`，等价于 `y-m+1 <= b <= y`。

因此，加入一颗苹果，相当于给所有这些底边位置的覆盖计数加 1；移除苹果则减 1。线段树维护“区间加、全局最大值”，最大值达到 c 就可行。

只需枚举输入点中出现过的 y 值作为候选底边：任何可行方案都能把底边上移到其所覆盖苹果的最小 y，而不丢失这些苹果。将这些候选 y 离散化，但比较距离时仍使用原坐标，不能用下标差代替坐标差。

代码里的 `RangeAddMax` 只查询整体最大值，因此无须下推标记；不变量为：

`maximum[node] = added[node] + max(maximum[left_child], maximum[right_child])`。

### 正确性

任意可行的一组苹果都出现在某次 x 窗口中；其最小 y 对应一个被枚举的底边。每颗窗口内苹果恰好给可以覆盖它的底边加一，因此根节点最大值就是当前 x 窗口内，某个纵向放置方案最多覆盖的苹果数。二分最终找到第一个可行的边长。

### 复杂度与易错点

每次判定至多加入和移除每颗苹果各一次，时间 `O(n log n)`。总时间 `O(n log n log U)`，空间 `O(n)`；`U <= 10^9`，最多约 30 次判定。

不能建立 `10^9 × 10^9` 网格，不能只使用部分数据的 1000 坐标范围。相同 x 或相同 y 完全合法，只保证 `(x,y)` 整对不重复。`c=1` 时答案为 1。
