# 第二题：多多字符串

来源：用户提供的题面截图，页面标题标注“拼多多 2026-9-22”；未独立核实为公司官方发布。本页完整整理截图中的题目规则、输入输出、约束和样例。

## 题目描述

有一个只包含小写字母 `a` 和 `b` 的字符串。

一个字符串是“多多字符串”，当且仅当它可以被分成连续的三段：第一段只包含 `a`，第二段只包含 `b`，第三段只包含 `a`。任意一段都可以为空。

也就是说，目标形式是 `a...a b...b a...a`，记为 `a*b*a*`；星号表示重复零次或多次。

可以删除原字符串中的一些字符，也可以一个都不删，但不能改变剩余字符的先后顺序。请问能够得到的最长“多多字符串”有多长？

## 输入描述

一行非空字符串 `s`，仅由小写字母 `a` 和 `b` 组成，`1 <= len(s) <= 5000`。

截图时间限制 1000 ms，空间限制 256 MB。

## 输出描述

输出一个整数，表示通过删除字符能够得到的“多多字符串”的最大长度。

## 截图样例

输入：

```text
abba
```

输出：

```text
4
```

解释：三个部分可以是 `a | bb | a`，不用删除字符。

## 解法：全部 a + 中间区间的最大收益

先保留所有 `a`，基线长度为 `count_a`。选择原串中的一个连续区间作为中间的 `b` 段来源：区间中的 `b` 全部保留、`a` 全部删除；区间外保留全部 `a`、删除全部 `b`。

相对基线，这个区间的收益为 `区间内 b 的数量 - 区间内 a 的数量`。将 `b` 记为 `+1`、`a` 记为 `-1`，求允许为空的最大子数组和：

```python
gain = max(0, gain + value)
best_gain = max(best_gain, gain)
answer = s.count('a') + best_gain
```

正确性：任意合法结果中的所有 `b` 都集中在中段。从首个保留的 `b` 到末个保留的 `b`，内部的 `a` 不能保留，外部的 `a` 都可以保留；所以必能由上述区间选择表达。没有保留 `b` 的情况对应空区间。

注意：求的是**删除后得到的子序列**，不是原串必须连续的子串。连续区间只是用于确定中间 `b` 段的来源。

时间 `O(n)`，辅助空间 `O(1)`。全 `a`、全 `b`、只有一个字符都自然覆盖。
